# 404-Ryo.github.io

Ryo の個人ポートフォリオサイトです。
ギリシャ神話をモチーフにしたアニメーションヒーローから、自己紹介・代表制作物・スキル・連絡先へ続く日英対応のエディトリアルデザインです。

## 見る

→ https://404-ryo.github.io

## 使用技術

- Vite
- React + TypeScript
- Tailwind CSS
- Lucide React

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、`main` ブランチへの push 後は GitHub Actions から Pages へ公開されます。
