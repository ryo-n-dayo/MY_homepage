# ryo-n-dayo.github.io

Ryo の個人ポートフォリオサイトです。
1 ページに収まるシンプルなプロフィール構成（About / Projects / Skills）で、日英切り替えとライト・ダークテーマに対応しています。

## 見る

→ https://ryo-n-dayo.github.io

## 使用技術

- Vite
- React + TypeScript
- Tailwind CSS
- Lucide React

## 開発

```bash
npm install
npm run dev
```

本番ビルドは `npm run build`、`main` ブランチへの push 後は GitHub Actions から Pages へ公開されます。
